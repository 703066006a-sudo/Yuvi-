# 见因 · Market Atlas

用真实月 K 线查看美股、A 股与黄金期货历史事件，再按前因后果展开原因、结果和隐患。

## 本地预览

```sh
python3 -m http.server 8765 --directory dist
```

打开 http://127.0.0.1:8765/ 。纯静态网页，无需安装依赖。左右方向键切换事件，点击事件节点查看解释，点击每个原因块展开细节。

## 数据与覆盖

当前快照获取于 2026-10-04，来源 Yahoo Finance：标普 500（^GSPC，1985 年起）、上证指数（000001.SS，1997 年起）、黄金期货（GC=F，2000 年起）。月 K 线使用实际 OHLC，红跌绿涨，价格轴为对数尺度。最新月份可能尚未结束。黄金为期货，换月可能影响比较。

缺失月份留空；黄金 2003-04、2003-08、2005-02、2008-04 的 OHLC 不一致，已剔除。数据只是保存的快照，不会自动更新，也不覆盖市场全部历史。

`dist/monthly-prices.json` 保存行情与来源记录。`dist/events-catalog.json` 是研究目录，部分条目仍待核实；页面只显示与有效行情月份对应的事件。两组事件（1987 年股灾、2015 年 A 股波动）有更完整的交互解释，其他解释仍需继续研究。节点包含原始来源链接。

## 文件

- `dist/index.html`：网页、样式、交互与内嵌行情
- `dist/monthly-prices.json`：行情快照及来源
- `dist/events-catalog.json`：历史事件研究目录

金融资料保留原始来源；上传仓库不代表取得第三方行情的再分发许可。
